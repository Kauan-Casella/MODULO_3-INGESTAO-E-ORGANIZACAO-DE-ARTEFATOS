# Especificação de Requisitos

## Sistema
Plataforma de Gestão de Projetos.

## Requisitos funcionais

- RF01: O sistema deve permitir o cadastro de projetos.
- RF02: O sistema deve permitir o envio de documentos PDF.
- RF03: O sistema deve permitir consultar o histórico de versões.

## Requisitos não funcionais

- RNF01: O sistema deve permanecer disponível mesmo quando um microsserviço estiver indisponível.

## Critérios de aceitação

- O usuário consegue cadastrar um projeto.
- O usuário consegue enviar um documento.
- O sistema registra a versão do documento.
